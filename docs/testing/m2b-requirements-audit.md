## Deliberate limits

- Different incoming groups cannot be linked to each other in this slice: keep separate or skip.
- Import attachment keeps all existing edition metadata; field-level reconciliation is manual-only.
- No exact ISBN evidence means no suggested attach target. Users can cancel and use the existing
  book's explicit Add Physical Copy action instead.
- An invalid copy row skips its entire portable group after the final disclosed confirmation;
  conflicting group bibliographic definitions require correcting the file rather than guessing.
- Existing internal legacy import semantics remain available for compatibility and create separate
  editions, never inferred links. Legacy renderer calls cannot bypass duplicate consent: their unreviewed defaults are validated. The desktop flow uses independently validated plans.
