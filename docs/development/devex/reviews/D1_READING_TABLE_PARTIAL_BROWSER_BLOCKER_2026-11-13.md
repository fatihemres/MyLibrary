1. **Node/Playwright host:** Browser launch through child-process control returned `spawn EPERM` and a separate capture helper returned an ffmpeg subprocess `EPERM`; additional tooling calls returned other host/runtime errors. These may reflect tool-host policy or process restrictions. The origin was **not independently isolated**.
2. **Google Chrome headless attempt:** reported valid Google vendor signature, executable version `157.0.8103.52`, and a **D1-local browser profile**. Chrome stderr showed `Crashpad CreateFile: Access denied`, followed by fatal Mojo platform-channel / IPC startup and crash-server failures. A user screenshot showed an `msedge.exe` unknown software exception `0x80000003`; Codex's available event-log query did **not** independently corroborate the exception. **Exact browser exit codes were not preserved**, and root cause remains unconfirmed.

The Computer Use host did not grant Google Chrome interaction. This is an **access-control result**, not evidence that the Chrome browser content was tested. No ordinary-speed visual playback or motion acceptance was legitimately completed.
