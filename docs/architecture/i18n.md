# Localization and accessibility foundation

The UI uses i18next/react-i18next with local English and Turkish JSON resources. `src/i18n/index.ts` defines fallback, locale selection, plural interpolation, direction and Intl date/number/currency helpers. English is the fallback; Turkish system locales select Turkish on first use. Settings → Language & region → Application language persists `ui_language` in SQLite and mirrors it in localStorage for startup. Book `language` and original-language fields are independent and never translated.

Components use translation keys. Central V1 metadata/status/route definitions retain their stable English identifiers; `label()` maps **built-in labels only** to keys at the display boundary. Never pass titles, author names, custom-field names, notes, shelf names or other user data to this function. Option values and exported JSON/CSV values remain canonical. Add new normal UI text to both resource files rather than component literals. Technical errors remain inspectable; Turkish shows translated known validation or a localized failure summary with expandable original diagnostic detail.

To add a language: add a resource with key parity and plural forms, register its locale/direction, test fallback and Intl behavior, then advertise it in Settings. German/French/Spanish/Italian/Arabic are future registry entries only. No translation service receives library content. Native OS file-picker chrome follows the OS language; installer localization is separate.

Logical inline CSS replaces physical spacing/alignment in navigation, forms, tables and dialogs. Future RTL direction is computed independently from current supported locales; directional hierarchy icons flip and file/code values remain LTR. RTL readiness is not an Arabic translation or full RTL certification.

Existing dialog focus trapping, explicit cancel-first destructive confirmations, unsaved-edit warnings and reduced-motion handling remain. Foundation adds semantic required-title validation, visible focus and forced-colors treatments. Full screen-reader and platform assistive-technology certification is still outside this baseline.

Tests map I18N-001…004 to resources, fallback, preference storage, unchanged book data, formatting and plurals. Real Windows checks exercise live switching and restart against synthetic libraries.

References: https://www.i18next.com/principles/fallback and https://www.i18next.com/translation-function/plurals .
